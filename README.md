# Знеструмко 2.0

Telegram-бот для підписок на графіки відключень з `be-svitlo.oe.if.ua`.

## Запуск

Для Windows можна просто двічі натиснути `setup.bat`. Скрипт створить `.venv` і встановить усі бібліотеки. Після цього запускайте `start.bat` — він активує середовище та запустить бота.

1. Встановіть Python 3.11 або новіший.
2. Створіть віртуальне середовище та встановіть залежності:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

3. Створіть `.env` на основі `.env.example` і вставте новий токен бота.
4. Запустіть:

   ```powershell
   python bot.py
   ```

Після запуску бот показує нижню клавіатуру з кнопками для підписки, відписки, перегляду черг, графіка, таймера до зміни світла та довідки. Команди `/subscribe 5.2`, `/unsubscribe 5.2`, `/tomorrow 5.2`, `/subscriptions` також залишаються доступними.
Графік перевіряється кожні 10 хвилин, а повідомлення надсилається лише після зміни збереженого графіка.
